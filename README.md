# 国标麻将算番

按中国大众麻将录入牌型：只填手牌，不设合张，不设副露。番种仍按国标 81 种计算。满 8 番起和。没有其他番时计无番和 8 番。花牌每张 1 番。

## 使用

用浏览器打开 index.html。

1. 点选牌张。同一张可点多次，第 5 次清除。
2. 顺子、刻子、杠子或对子加入手牌。可以一次选多张，能拆开的组会一起加入。对子不需要单独设置。
3. 七对把 7 个对子加入手牌，并选择“七对”。
4. 十三幺、全不靠把 14 张牌加入特殊散牌。
5. 组合龙把 147、258、369 这 9 张加入特殊散牌，再加 1 个面子和 1 个对子。
6. 填写花牌张数、和牌方式和听牌类型，然后计算。清空会复位牌型、条件和计分结果。

边张、坎张、和绝张、海底与杠上开花需要自行勾选。单钓将也需要自行勾选。没有副露，门前清按点和计算。

## 说明

计分包含国标 81 个番种，并按常见不计关系去掉重复番。组合龙若被顺子拆开，需要改用特殊散牌录入。和绝张不会自动判断牌河余张。
